# GONGCHA
병원 포털 사이트

## 🔗 바로가기
[gongcha](https://hyungyeong77.github.io/gongcha)
<br><br><br>

## 💡 프로젝트 소개
공차 페이지를 모작하기 위해 제작한 사이트입니다.

## ✅ 개발 기간
* 25.10.09 ~ 25.11.07

## ⚙️ 개발 환경
- 언어 : JSX / SCSS / TS
- 프레임워크 : Next.js
- 라이브러리 : React
- 도구 : VS Code / Git
- 배포 : Github Pages

## ✨ 주요 기능
- 반응형 웹 디자인
- Interactive UI/UX
  * swiper 슬라이더 구현
  * 물리엔진 구현
  * Intersection Observer 애니메이션
  * 마우스 오버 & 클릭 애니메이션
  * 관성 스크롤링
